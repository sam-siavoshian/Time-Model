# Current Report Manifest

`manifest.json` centralizes the report artifacts that should be treated as
current for the manuscript and reproducibility work. It is generated from
`claims.json` and `schema.json` by `scripts/generate_current_manifest.py`.
It also marks known stale, superseded, contaminated, and historical outputs.

Status meanings:

- `current`: paper-current or intended canonical input.
- `current_with_caveat`: usable, but the manifest records a known reporting or
  interpretation caveat.
- `superseded`: retained for provenance, but replaced by a newer artifact.
- `contaminated`: generated by a known flawed evaluation path; do not cite as a
  result.
- `historical`: old experiment evidence retained for provenance.

Archive policy:

Historical and superseded files have been moved under `reports/archive/` with
per-folder `MANIFEST.md` files. Current evidence remains at its original report
paths so existing paper references stay readable.

Validation:

```bash
python3 scripts/generate_current_manifest.py --check
```
