# IPCN Training Dataset

Synthetic + curated public-domain corpora for training Involuntary Prefix Consolidation Networks. v1.

## Datasets

### 1. Temporal Latent World (`data/latent_world/`)

Hidden-simulator event streams with real-minute timestamps. Tests Δτ-driven memory evolution + silent-gap dynamics.

| Split | File | Streams | Nominal tokens |
|---|---|---|---|
| train | `train_1k.jsonl` | 15,000 | ~1,024 |
| train | `train_2k.jsonl` | 15,000 | ~2,048 |
| train | `train_4k.jsonl` | 10,000 | ~4,096 |
| train | `train_8k.jsonl` | 5,000 | ~8,192 |
| test | `test_16k.jsonl` | 2,000 | ~16,384 |
| test | `test_32k.jsonl` | 1,000 | ~32,768 |
| test | `test_64k.jsonl` | 500 | ~65,536 |
| test | `test_128k.jsonl` | 200 | ~131,072 |
| valid | `valid_1k.jsonl` | 500 | ~1,024 |
| valid | `valid_4k.jsonl` | 500 | ~4,096 |
| valid | `valid_16k.jsonl` | 100 | ~16,384 |

Each stream has 2-3 rules (decay / delayed transition / periodic), 30-9860 events depending on bin, a silent gap (60-1024 min) before the question, and 3 questions tagged Δτ-sensitive or insensitive.

### 2. Memory-Biased Ambiguity Suite (`data/ambiguity/`)

Three-phase examples testing whether prior memory bends interpretation of ambiguous input.

| Split | Examples |
|---|---|
| train | 100,000 |
| valid | 10,000 |

5 families × 2 senses each: `bat_animal_vs_sport`, `bank_river_vs_financial`, `crane_bird_vs_machine`, `mip_animal_vs_vehicle` (invented word for training-data leakage control), `rin_social_reliability`.

### 3. Consolidation Ladder (`data/consolidation/`)

Rules introduced + repeatedly queried + removal test + contradiction test. Tests slot → weight migration.

20,000 rules. 5 rule types: reliability, decay, mapping, permission, sequencing. 60-100 query chunks per rule.

### 4. Chronometric Pairs (`data/chronometric_pairs/`)

10,000 paired streams: same visible text, two different Δτ values. For Prediction 6 eval.

### 5. Contradiction Pairs (`data/contradiction_pairs/`)

5,000 pairs: ambiguous input × memory swap, plus explicit-input variant that resolves ambiguity. For Prediction 7 eval.

### 6. Real Text (`data/real_text/`)

10 public-domain Project Gutenberg books. ~6,000 chunks of ~256 tokens each. For Phase 3 mixed-LM training.

## Schemas

All datasets use pydantic schemas defined in `data_gen/schemas.py` (versioned, HF-release-ready). Each example carries `schema_version`.

## Tokenized binary caches

`data/tokenized/` contains `.tokens.bin` (uint16 flat token array) + `.boundaries.npy` (int64 [start, end) per example) + `.meta.json` per dataset. Loadable via numpy memmap for fast training-time access.

Vocab: GPT-2 BPE (`tiktoken.get_encoding("gpt2")`). Will swap to Qwen3 tokenizer if we graft on a pretrained base.

## Reproducibility

All synthetic generators are seeded. Identical seed → identical output. Seeds per dataset:

| Dataset | Base seed |
|---|---|
| Latent World train_1k | 1,000,000 |
| Latent World train_2k | 2,000,000 |
| Latent World train_4k | 3,000,000 |
| Latent World train_8k | 4,000,000 |
| Latent World test_16k | 5,000,000 |
| Latent World test_32k | 6,000,000 |
| Latent World test_64k | 7,000,000 |
| Latent World test_128k | 8,000,000 |
| Latent World valid | 9,000,000+ |
| Ambiguity train | 20,260,512 |
| Ambiguity valid | 99,999,999 |
| Consolidation | 30,000,000 |
| Chronometric pairs | 40,000,000 |
| Contradiction pairs | 50,000,000 |

To regenerate from scratch:

```bash
uv run python -m data_gen.generate_all_latent_world --split all
uv run python -m data_gen.ambiguity_generator --n 100000 --out data/ambiguity/train.jsonl
uv run python -m data_gen.ambiguity_generator --n 10000 --out data/ambiguity/valid.jsonl --seed 99999999
uv run python -m data_gen.consolidation_generator --n 20000
uv run python -m data_gen.chronometric_pairs --n 10000
uv run python -m data_gen.contradiction_pairs --n 5000
uv run python -m data_gen.real_text_acquire
uv run python -m data_gen.tokenize_all
uv run python -m data_gen.validate
```
